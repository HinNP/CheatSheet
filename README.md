## 🚀 Getting Started

### Prerequisites

No special prerequisites are required! Simply browse the documentation in the `docs/` directory to find the cheatsheet you need.

### Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/HinNP/CheatSheet.git
   cd CheatSheet
   ```

2. **Browse the docs**
   Navigate to the `docs/` directory and open any markdown file in your favorite text editor or markdown viewer.

3. **Explore code examples**
   Check out the `code-examples/` directory for practical, runnable code samples.
